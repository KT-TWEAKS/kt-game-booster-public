# Contribuindo ao KT Game Booster

Contribuições são bem-vindas. Para alterações grandes, abra uma issue primeiro; mantenha o pull request limitado a um objetivo e não altere perfis de otimização sem explicar o impacto e a reversão.

## Antes de enviar

1. Execute os testes disponíveis: `node --test website/*.test.mjs`.
2. Para o aplicativo Windows, execute `build.bat` em uma máquina com Visual Studio Build Tools e C++ x64.
3. Inclua evidência visual em mudanças no site e explique qualquer efeito em desempenho, anticheat ou restauração de sessão.

Ao contribuir, você concorda com o [Código de Conduta](CODE_OF_CONDUCT.md) e a [Política de Segurança](SECURITY.md).
