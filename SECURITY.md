# Política de Segurança

Relate falhas de forma privada pela [advisory de segurança](https://github.com/KT-TWEAKS/kt-game-booster-public/security/advisories/new). Não abra uma issue pública com instruções de exploração.

Informe a versão, passos de reprodução, impacto e mitigação. A branch `main` é a versão acompanhada.
