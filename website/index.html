RECURSOS

Cada lever é uma decisão documentada.

Nada de caixa-preta: tudo é código aberto, aplicado em ordem verificada e desfeito por journal de snapshots no encerramento.

Detecção automática de jogos

Mais de 260 executáveis embutidos com níveis de confiança: nome, caminho de loja (Steam, Epic, Riot, GOG, Xbox, Ubisoft, EA, Battle.net), launcher-chain e validação de manifest no EGS. Spotify, Discord e OBS nunca são tocados.

Presets por título

61 títulos (101 regras de EXE) já entram configurados: competitivos herdam o perfil torneio (latência máxima) e títulos de mundo/campanha o segundo plano — tudo antes da trava de anticheat.

Governor automático

Otimização por tick de 1 segundo: prioridade HIGH, I/O alto, memory priority e prioridade de página para o jogo. Ao encerrar, o motor devolve prioridade, afinidade, EcoQoS, serviços e shell.

Timer 0.5 ms

Resolve o timer do Windows durante o jogo via NtSetSystemInformation com privilégio verificável. O padrão do Windows é ~15.6 ms; o card TIMER do Bench mostra o valor real entregue.

CPU Sets de P-cores

Em máquinas híbridas, o jogo é fixado nos núcleos de performance via API oficial de CPU Sets. Em CPUs convencionais, o conjunto de núcleos fica configurável no gamemode.toml.

Fundo em EcoQoS

Apps de fundo caem no modo de eficiência de CPU e I/O, com trilha de rede no regime de economia, enquanto o jogo roda. Limitação suave por CPU com lista de exceção editável na aba Jogos.

Modo jogo no painel

O painel deve custar zero para a sessão: quando um jogo é detectado, animações e sombras off, 20 fps de teto e opção de ir para a bandeja. Balão de aviso e retorno automático pelo ícone.

Planos de energia gaming

Par de planos dedicado: um para a sessão de jogo e outro restaurado na saída. GUIDs configuráveis no TOML, restauração coberta pelo journal.

Updater com SHA-256

O app baixa o release oficial, valida o hash publicado antes de aplicar, preserva config e perfis e reinicia limpo. Nada fica preso no sistema.

Bench de latência v2

Score composto, timer real via ntdll, 6,6 milhões de amostras de scheduler e leitura 4KB sem cache no disco. Se uma medição falha, o peso renormaliza e o card mostra honestamente —.

Como o score é construído

Timer vale 35%, scheduler 35% e I/O 30%. Cada parte recebe nota por curva (0.5 ms ≈ nota 100; sched ≤ 50 µs ≈ 96; I/O NVMe 30 µs ≈ 96).

Como ler

≥ 85 excelente — resposta de input no nível dos apps de referência.
70–84 bom — saudável, ganho só com tweaks finos.
50–69 média — timer + plano resolvem.
< 50 sensível — algo drena o sistema.

SEGURANÇA / ANTICHEAT

Feito para não te custar um ban.

Tudo que pode flagar anticheat é opt-in, documentado e reversível. Em sessões AC, o modo seguro derruba limitadores e usa apenas APIs user-mode comuns.

SEMPRE aplicado com segurança

  • Sequência AC-safe: jogos com anticheat de kernel sobem os levers em ordem compatível (prioridade HIGH mantida, suspensões/serviços e limiter desligados).
  • Snapshot journal: cada mudança é registrada e desfeita na ordem inversa — inclusive em Ctrl+C ou crash.
  • User-mode: sem driver de kernel, sem serviço assinado próprio, sem patch de memória de terceiros.
  • Chaves de risco ficam OFF por padrão no TOML e ligadas só por você.

NUNCA é feito

  • Não mata explorer, dwm ou winlogon — quebra de sessão e flag conhecida.
  • Não re-injeta input (SendInput) — disparo de ban, não otimização.
  • Não instala serviço, driver ou tarefa oculta para "persistir boosts".
  • Não envia telemetria — export JSON/CSV é manual e sai do seu disco.

Requisitos

  • Windows 10 (build 19045+) ou Windows 11, x64
  • Privilégio de administrador — a UI pede uma vez
  • ~500 KB, sem runtime adicional
  • Antivirus: assinatura de instalador via NSIS; hash SHA-256 publicado em cada release

Instalação e saída

  1. Baixe o EXE único (ou o instalador) e confira o .sha256.
  2. Execute como administrador.
  3. Abra o jogo — detecção, preset e resto são automáticos.
  4. Para remover: feche o app (restauração imediata) e apague a pasta, ou desinstale pelo Windows. Se ligou o auto-início, a chave HKCU sai junto.

Verifique a origem do arquivo e confira o SHA-256 antes de executar. O app nunca pede conta, login ou rede — a única conexão é o updater opcional de release.
